# Settings

Global Jenkins connection metadata, the selected interface language, and notification preferences are stored as one Codable JSON value in UserDefaults through the main-actor `AppSettings` facade. The API token is stored separately in Keychain under the normalized controller URL and user identity. Open job tabs and selection are window state persisted by the actor-backed SQLite app-state store. Changing the controller identity clears restored job tabs and notification baselines.

The Language destination offers ten explicit languages using native-script names: English, Spanish, French, German, Portuguese, Simplified Chinese, Traditional Chinese for Hong Kong, Traditional Chinese for Taiwan, Japanese, and Korean. Selecting a language updates the main window, Settings window, commands, notifications, dates, durations, and number formatting immediately without relaunching. Each language has a complete Swift dictionary catalog; tests enforce exact key parity, required format placeholders, non-empty values, and a maximum ratio of values identical to English. Saved values from the earlier system-language and named-enum representation decode into the new stable language-code representation.
